# Nirman Consultants

Architectural, Structural Engineering & Interior Design Portfolio Website.

## 🏢 Overview
Official multi-theme presentation and portfolio web application for **Nirman Consultants** (Govt. Approved Valuers, Structural Engineers, and Architects in Kanpur & beyond).

## 🚀 Themes Included
- **Creative Modern Theme**: Ultra-modern architectural dark/light aesthetic showcasing 800+ landmark projects, comprehensive expertise, service details, and responsive navigation.
- **Nirman Consultants Classic / Themes (Modern, Luxury, Contemporary)**: Alternate design variants tailored for client presentations and architectural consulting.

## 📱 Features
- Fully responsive design optimized for mobile, tablet, and desktop screens.
- Interactive mobile hamburger menus with expandable sub-menus.
- Fast, optimized assets and clean code structure.
- Root auto-redirection to the primary showcase theme.

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript (Vanilla / Modern jQuery integrations)
- Swiper / Owl Carousel / NiceSelect / Magnific Popup UI components
